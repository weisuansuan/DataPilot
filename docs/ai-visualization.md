# AI 查询结果图表与洞察

`frontend/src/analysis/result-analysis.js` 提供纯确定性的图表推荐、配置和洞察函数。它只读取经过服务端安全校验并由 MySQL 执行的 `columns` 和 `rows`，不会请求额外模型，也不会执行 SQL 以外的模型内容或动态 JavaScript。

## 图表规则

| 查询结果结构 | 推荐展示 |
|---|---|
| 一行、无分类维度、1–4 个数值字段 | KPI 数字卡片 |
| 一个时间维度、至少两期、最多 3 个数值指标 | 折线图 |
| 一个分类维度、最多 30 行、最多 3 个数值指标 | 柱状图 |
| 一个地区/分类维度 + 一个时间维度、最多 30 行、最多 12 个分类 | 两三期用分组柱状图；四期及以上用分组折线图 |
| 2–8 个非负分类值且问题提到占比/比例/构成/组成 | 饼图 |
| 空结果、维度结构无法识别、超过 30 行或超出安全数值范围 | 原始表格 |

百分比按 0–1 比率格式化为百分数；金额、数量和日期使用中文格式或保留数据库返回的 ISO 日期字符串。后端将 DECIMAL 和 BIGINT 以十进制字符串输出，浏览器无法安全转换为数值的结果会退回原始表格并提示精度原因。所有可视化可在图表和原始表格间切换；切换时释放旧 ECharts 实例，再创建新实例；空结果显示为空，不生成图表或结论。ECharts 和可视化组件通过动态导入加载，ECharts 6 使用 `echarts/core` 的按需模块并由 Rolldown 分拆图表、组件和核心块。

## 事实洞察

确定性分析可输出最大变化地区、按指标排序的前三项、时间序列首末变化和单值 KPI。地区月度结果优先按每个地区的首末月份计算变化；有明确变化字段时直接按该字段排序。结论附带字段、比较行数或起止时间作为依据，并明确不推断因果。空值、无有效指标或超出浏览器数值比较精度时不输出排名或趋势。

洞察服务边界是 `buildInsights(columns, rows, question)`。后续若接入模型解释，模型输出只能作为独立的推测文本展示，事实结论仍应绑定经过校验的 SQL 结果和字段来源。
